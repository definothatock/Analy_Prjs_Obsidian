# Game Design Research Vault

This repository is a structured Obsidian vault for game analysis, design research, and project planning. It is organized to help visitors quickly understand the main themes of the collection and navigate toward materials that may be useful for design study, system thinking, and project development.

# Main Directories

### Methodology
This directory defines the thinking methods behind the project. It captures the standards for analysis, terminology, and design frameworks used throughout the vault.

### Plannings
This folder contains concept planning, iterative project direction, and system ideas that are moving toward actual project structure. It is the main place for future-facing design development.
### Implementation
This folder is for implementation-oriented planning after the design direction has been clarified. It focuses on practical structure and execution rather than broad conceptual discussion.

### Analysed Topic
This folder contains analysis notes, design discussions, and reactions to specific games, genres, and creative questions. It is where the project turns observations into written argument and interpretation.
