# 游戏设计研究库

这个仓库是一个结构化的 Obsidian 知识库，用于游戏分析、设计研究和项目规划。它的组织方式旨在帮助访问者快速理解收藏内容的主要主题，并导航到对设计研究、系统思维和项目开发可能有用的资料。

# 主要目录

### Methodology / 方法论
这个目录定义了项目背后的思考方法。它记录了整个知识库中使用的分析标准、术语规范和设计框架。

### Plannings / 规划
这个文件夹包含概念规划、迭代中的项目方向以及逐渐向实际项目结构靠拢的系统想法。它是面向未来设计开发的主要场所。

### Implementation / 实施
这个文件夹用于在设计方向明确之后进行实施导向的规划。它关注的是实际结构和执行，而不是广泛的概念讨论。

### Analysed Topic / 分析主题
这个文件夹包含对特定游戏、类型和创意问题的分析笔记、设计讨论和反应。这里是项目将观察转化为书面论证与解读的地方。
